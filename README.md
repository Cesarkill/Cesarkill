<details>
<summary><sub>Lendo os instrumentos</sub></summary>

- **Disco de acreção:** cada partícula representa um dia do último ano; dias com mais contribuições brilham mais forte e orbitam mais perto do horizonte de eventos. As três faixas giram em velocidades keplerianas distintas (a interna gira mais rápido), com efeito Doppler simulado no limbo esquerdo.
- **Órbita:** volume de contribuições por mês em trajetória polar fechada; o farol pulsante marca o mês de maior atividade.
- **Composição espectral:** proporção de código por linguagem nos repositórios próprios.
- **Tema claro:** renderizado como chapa fotográfica negativa, à moda dos antigos catálogos astronômicos.

<sub>Arte vetorial animada em SVG puro, gerada automaticamente via GitHub Actions. Animações param se o sistema solicitar movimento reduzido (`prefers-reduced-motion`).</sub>

</details>
